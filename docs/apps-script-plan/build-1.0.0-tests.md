# בדיקות ל-apps-script-build 1.0.0

כל בדיקה בשיחה חדשה ב-Gemini, עם הסקיל מותקן (גרסה 1.0.0). בדיקה 5 יש לה המשך באותה שיחה.

מה בודקים בכל תשובה, חוץ ממה שכתוב בכל בדיקה:
- בנה את הכלי, ולא הציע Google Forms או נוסחאות במקומו.
- כל קובץ מלא, בלי "שאר הקוד נשאר". `Card.gs` אחרון, עם "עדכון מס' 1".
- כל עברית בקוד בתוך backticks. אחרי `getSheetByName` יש בדיקה. עמודות לפי שם כותרת.
- יש `runCheck`: כותבת שורה ומוחקת אותה, "הכול עובד", בלי מייל ובלי שיתוף.
- בהוראות: Select all בחלון ההרשאות.
- 3 שורות ב"אם משהו לא עובד". בלי פנייה בזכר או בנקבה.

## בדיקה 1: תפריט בגיליון, הכותרות בבקשה

מה אמור לקרות: קוד מיד, בלי שאלות. `onOpen` שקוראת לפונקציה אחת. פריט `בדיקה` בתפריט שמפעיל את `runCheck`. שם הלשונית והכותרות בקבועים. בלי "גרסה חדשה" (זה לא אפליקציית אינטרנט).

```
יש לי גיליון של השאלת ציוד בבית הספר. הלשונית נקראת "השאלות", והכותרות הן: שם המורה | פריט | תאריך השאלה | להחזיר עד | הוחזר
אני רוצה כפתור בתפריט שצובע באדום כל שורה שעבר התאריך שלה ועוד לא הוחזרה, ובירוק כל מה שהוחזר. אני לא יודע לתכנת.
```

## בדיקה 2: טריגר שבועי עם מייל

מה אמור לקרות: `TEST_MODE = true`, היום והשעה בקבועים, `startTrigger` שמוחקת טריגר קודם, `stopTrigger`. `runCheck` מהעורך, ולא שולחת מייל. בלי `getUi()` בלי `try`.

```
אני רכזת שכבה. יש לי גיליון "תורנויות" עם העמודות: תאריך | מורה תורן | מקום. אני רוצה שכל יום ראשון ב-7 בבוקר יישלח לי מייל עם התורנויות של השבוע הקרוב.
```

## בדיקה 3: דף בקישור לצוות

מה אמור לקרות: `Code.gs`, `Index.html` (השם `Index`), `Card.gs`. `withFailureHandler` לכל קריאה, הכפתור חוזר למצב פעיל, `LockService` סביב הכתיבה, `dir="rtl"`. בהוראות: קישור `/dev` לבדיקה, ו"פריסה ← ניהול פריסות ← עריכה ← גרסה חדשה ← פריסה" אחרי שינוי.

```
אני רוצה דף שהמורים בבית הספר פותחים בקישור, בוחרים חדר (מעבדה, ספרייה, אולם) ותאריך ושעה, ושההזמנה תיכנס לגיליון שלי. אם החדר כבר תפוס באותה שעה, שיגיד להם.
```

## בדיקה 4: גיליון קיים, בלי כותרות בבקשה

מה אמור לקרות: הודעה אחת עם עד 4 שאלות (שם הלשונית, כותרות, ...), עם ברירות מחדל. בלי קוד. בלי שמות מומצאים של לשוניות או כותרות.

```
יש לי גיליון נוכחות של הכיתה. תכתוב לי Apps Script עם כפתור בתפריט שמראה לי מי חיסר 3 פעמים או יותר החודש.
```

הנוסח הראשון של הבדיקה ("אני רוצה שהגיליון יראה לי מי חיסר 3 פעמים", בלי "Apps Script" ובלי "כפתור") לא הפעיל את הסקיל: ג'מיני נתן נוסחאות COUNTIF ועיצוב מותנה. זו תשובה סבירה לבקשה בלי קוד, ולכן שיניתי את הבדיקה.

## בדיקה 5: טופס שמעדכן לשונית, עם גרשיים בעברית

מה אמור לקרות: טריגר `onFormSubmit` (או בניית הסיכום מכל התשובות), לא "תשתמשו בתוספת של Forms". הכיתות `ז'1`, `ח'2` בתוך backticks. בדיקה ש-`e` קיים. `LockService`. הלשונית "סיכום לפי כיתה" נבנית מחדש, ולשונית התשובות לא משתנה.

```
יש לי טופס Google Forms להרשמה לטיול שנתי. התשובות נכנסות לגיליון, ללשונית "תגובות לטופס 1", עם העמודות: חותמת זמן | שם התלמיד | כיתה | אישור הורים | הערות
הכיתות הן ז'1, ז'2, ח'1, ח'2. אני רוצה שבכל פעם שמישהו נרשם, לשונית "סיכום לפי כיתה" תתעדכן: כמה נרשמו מכל כיתה, וכמה מהם עם אישור הורים.
```

המשך באותה שיחה, אחרי התשובה:

```
תוסיף גם שיישלח לי מייל כשכיתה מגיעה ל-30 נרשמים.
```

מה אמור לקרות: שינוי בכלי שכבר נבנה באותה שיחה. כל קובץ שהשתנה מלא, `Card.gs` עם "עדכון מס' 2", `TEST_MODE`, ומייל אחד לכל כיתה (לא בכל הרשמה אחרי 30).
