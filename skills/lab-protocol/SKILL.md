# פרוטוקול מעבדה וטופס הזמנת ציוד

## התוצר: 2 קבצי Word

1. **`protocol.docx`, דף לתלמיד:** הפרוטוקול. בסוף, בעמוד נפרד, "מפתח תשובות ותוצאות צפויות" למורה.
2. **`order.docx`, טופס הזמנת ציוד ללבורנט:** רק הטבלה ופרטי ההזמנה, בלי הפרוטוקול. המורה שולח אותו ללבורנט כמו שהוא.

- **אל תכתוב את הדפים בצ'אט.** בנה את שני הקבצים לפי "שלבי העבודה" בסקיל format-equations-for-hebrew-worksheets: Markdown ← pandoc ← הפונקציה `build`.
- **2 הרצות קוד, קובץ אחד בכל הרצה.** באפליקציה של Gemini, הרצה שבונה 2 קבצים לא מציגה אותם למורה, ואין לו מה להוריד.
  1. הרצה 1: הגדר את `build` מהסקיל format-equations-for-hebrew-worksheets ואת `order_table` ו-`check` שלמטה, הגדר את `items`, `md_protocol` ו-`md_order`, הרץ `check`, ואז `build(md_protocol, "protocol.docx", chem=True)`.
  2. הרצה 2: הגדר שוב את `build`, את `order_table` ואת `items`, בנה את `md_order`, ואז `build(md_order, "order.docx", chem=True)`.
- אין `$` בכלל. חומרים (H₂O₂, ‏NaCl), ריכוזים ויחידות כתובים כטקסט רגיל עם תווי יוניקוד.
- כל Markdown מתחיל ב-`dir: rtl` כמו בסקיל העיצוב. שורה ריקה לפני כל רשימה וכל טבלה.

## לפני שמתחילים

צריך לדעת: **איזה ניסוי** (או נושא), **כיתה**, **מספר קבוצות**.

- אם הניסוי או הנושא חסרים, שאל שאלה אחת קצרה: איזה ניסוי, לאיזו כיתה, וכמה קבוצות.
- אם רק מספר הקבוצות חסר, קבע 8 קבוצות. אם רק הכיתה חסרה, כתוב לתיכון. כתוב בצ'אט בשורה אחת מה קבעת.
- אם המורה הדביק פרוטוקול משלו, שמור על השלבים שלו. תקן רק טעות או סכנה, וכתוב בצ'אט מה תיקנת.

## מבנה הפרוטוקול (protocol.docx)

1. כותרת: שם הניסוי, וכיתה. שורה למילוי: שמות חברי הקבוצה, תאריך.
2. **מטרת הניסוי:** משפט אחד.
3. **רקע קצר:** 3-5 משפטים עם המושגים שהתלמיד צריך.
4. **שאלת חקר והשערה:** "מה ההשפעה של ... על ...?" והשערה עם הסבר. אם זה ניסוי של תצפית (מיקרוסקופ) או של הדגמה, כתוב רק מטרה.
5. **חומרים וציוד לקבוצה:** רשימה עם כמות לכל פריט.
6. **בטיחות:** 3-6 נקודות שקשורות לניסוי הזה, לא רשימה כללית.
7. **שלבי העבודה:** רשימה ממוספרת. פעולה אחת בכל שלב, עם כמות, זמן וטמפרטורה כשצריך. סמן איפה מודדים ומה רושמים.
8. **טבלת תוצאות ריקה:** עמודות עם שם ויחידה, ושורות ריקות למילוי.
9. **שאלות לדיון:** 3-5 שאלות: תיאור התוצאות, הסבר, מסקנה, מקור טעות אפשרי.
10. `## מפתח תשובות ותוצאות צפויות` (`build` מעביר לעמוד חדש): מה צפוי לצאת, ותשובות לשאלות. הוסף שורה: "תוצאות בכיתה יכולות להיות שונות מעט."

## טופס ההזמנה (order.docx)

- כותרת "הזמנת ציוד למעבדה". שורות למילוי: שם המורה, כיתה, תאריך הניסוי ושעה. מספר הקבוצות כתוב.
- טבלה אחת עם העמודות: **פריט | כמות לקבוצה | מספר קבוצות | כמות כוללת | הערות ללבורנט**.
- **את הטבלה בונה רק הפונקציה `order_table`.** אל תכתוב את הכמות הכוללת בעצמך. הפונקציה מחשבת: כמות לקבוצה × מספר קבוצות, ועוד 10% לחומר מתכלה, מעוגל למעלה. ב-mL וב-g: לעשרות הבאות. ציוד שחוזר ללבורנט (מבחנות, מיקרוסקופ) בלי עודף.
- **כמות לקבוצה = כל מה שקבוצה אחת משתמשת בו בכל השלבים יחד.** חבר את הכמויות מהשלבים לפני שאתה כותב אותה. אותו שם פריט בדיוק בשלבים, ברשימת הציוד ובטופס.

```python
import math, re

def order_table(items, groups):
    """items: רשימה של (שם הפריט, כמות לקבוצה, יחידה, מתכלה True/False, הערה)"""
    rows = ["| פריט | כמות לקבוצה | מספר קבוצות | כמות כוללת | הערות ללבורנט |", "|---|---|---|---|---|"]
    for name, per, unit, consumable, note in items:
        total = per * groups * (1.1 if consumable else 1)
        total = math.ceil(round(total, 6))
        if consumable and unit in ("mL", "g"):
            total = math.ceil(total / 10) * 10
        rows.append(f"| {name} | {per:g} {unit} | {groups} | {total:g} {unit} | {note} |")
    return "\n".join(rows)

def check(md_protocol, md_order, items):
    problems = []
    for name, *_ in items:
        if name not in md_protocol:
            problems.append("פריט מהטופס חסר בפרוטוקול: " + name)
    for md in (md_protocol, md_order):
        if re.search(r"[؀-ۿ]", md):
            problems.append("יש אות בערבית בטקסט")
    for part in ("מטרת הניסוי", "בטיחות", "שלבי העבודה", "טבלת תוצאות", "שאלות לדיון", "מפתח תשובות"):
        if part not in md_protocol:
            problems.append("חסר חלק בפרוטוקול: " + part)
    print("בדיקה:", problems or "אין בעיות")
    return problems
```

- יחידה לפריט שסופרים: "יח'". למשל `("מבחנות", 6, "יח'", False, "נקיות ויבשות")`.
- את הכותרות של חלקי הפרוטוקול כתוב בדיוק כמו ב-`check`, כדי שהבדיקה תמצא אותן.
- אם `check` מדפיס בעיה, תקן והרץ שוב לפני שאתה מוסר את הקבצים.
- עמודת ההערות: ריכוז ואופן ההכנה של תמיסה ("תמיסת סוכרוז 0.5 M, להכין מראש 500 mL"), מה צריך להיות קר או טרי, ומה צריך להכין יום לפני.
- בסוף הטופס: "ציוד משותף לכיתה" (אמבט מים, מאזניים, מקרר), אם צריך.
- כל פריט בטבלה מופיע גם ברשימת הציוד בפרוטוקול, ולהפך. בדוק את זה בקוד, באותה הרצה.

## בטיחות: חובה

- השתמש רק בחומרים ובציוד שיש במעבדה של בית ספר.
- **אם הבקשה כוללת שלב מסוכן, אל תכתוב אותו.** כתוב חלופה בטוחה, וכתוב בצ'אט בשורה אחת מה החלפת ולמה. דוגמאות:
  - דם או רוק של תלמידים → עמילאז מסחרי, או מודל.
  - אתנול ליד להבה → אמבט מים חם.
  - חומצה או בסיס מרוכזים → תמיסה מהולה, בריכוז שהלבורנט מאשר.
  - גידול חיידקים מהסביבה → צלחות סגורות שלא פותחים, והשמדה אצל הלבורנט. או ניסוי עם שמרים.
- **הנקודה הראשונה בבטיחות תמיד:** "עובדים עם כפפות ומשקפי מגן לאורך כל הניסוי." גם כשהמורה לא ביקש.
- הוסף בסוף הבטיחות: "לבדוק את הפרוטוקול עם הלבורנט ולפי הוראות הבטיחות של בית הספר."
- אל תכתוב שם של תקנה או חוזר רשמי אם אתה לא בטוח שהוא קיים.

## דיוק בפרוטוקול

- **כתוב את הניסוי שהמורה ביקש.** אל תוסיף טיפולים או השוואות שהוא לא ביקש.
- **בדוק שכל כמות נכנסת לכלי.** מבחנה רגילה מחזיקה בערך 15-20 mL. חבר את כל מה שנשפך לאותו כלי. אם צריך יותר, כתוב כוס כימית. אם הכמויות של המורה לא נכנסות לכלי שלו, כתוב את זה בצ'אט בשורה אחת, והצע כלי גדול יותר או כמות קטנה יותר.
- מים מאמבט מים הם "מים חמים ב-<טמפרטורה>", לא "מים רותחים".
- **קרא את הקבצים פעם אחת לפני `build`, ותקן עברית:** שגיאות כתיב ("כעבור", לא "כבור"), מילים משובשות, ואותיות בערבית.
- בצ'אט: בלי `$` ובלי LaTeX.

## ההודעה בצ'אט

אחרי שני הקבצים, כתוב רק:
1. שורה אחת: מה יש בכל קובץ ("protocol.docx לתלמידים, order.docx ללבורנט").
2. שתי שורות ההודעה למורה מהסקיל format-equations-for-hebrew-worksheets.
3. רק אם צריך: מה קבעת (כיתה, מספר קבוצות), ומה החלפת בגלל בטיחות.

## דוגמה: order.docx

```python
items = [
    ("מבחנות", 6, "יח'", False, "נקיות ויבשות"),
    ("תמיסת H₂O₂ ‏3%", 30, "mL", True, "להכין מראש, לשמור בבקבוק כהה"),
    ("קוביות כבד טרי של 1 cm", 6, "יח'", True, "לחתוך בבוקר, לשמור במקרר"),
]
md_order = """---
dir: rtl
lang: he
---

# הזמנת ציוד למעבדה

שם המורה: ______ כיתה: י'2 תאריך הניסוי: ______ שעה: ______

מספר קבוצות: 8

""" + order_table(items, 8) + "\n"
```

התוצאה בטבלה: מבחנות 48, תמיסת H₂O₂ ‏270 mL, קוביות כבד 53.
